DESIGN PHILOSOPHY

Designed for the 8051 Architecture

HRTOS is developed specifically for the 8051 and MCS-51 microcontroller family. Its kernel and system services are designed around the architecture, memory model and resource constraints of these devices.

Rather than simply adapting a general-purpose operating system, HRTOS provides an embedded software foundation tailored to 8051-based applications.

The goal is to make complex embedded applications easier to structure, develop, maintain and extend.
