OVERVIEW

Interrupts in Real-Time Systems

Interrupts are essential to responsive embedded systems. They allow the processor to react to hardware events without relying entirely on continuous polling.

On 8051 microcontrollers, interrupt sources may include timers, external signals, serial communication and other peripheral events.

In a multitasking environment, interrupt handling must work together with task scheduling, context management and system resource protection.

HRTOS provides an integrated interrupt management model designed for the characteristics of the 8051 architecture.

Application Task

A task performs the remaining application processing when scheduled by the kernel.

This design separates immediate hardware response from application-level processing.

It helps keep interrupt service routines focused and allows more complex operations to execute in the task context.

NESTED INTERRUPTS

Priority-Aware Interrupt Processing

Interrupt nesting provides a mechanism for handling higher-priority events without requiring every interrupt to wait for lower-priority processing to finish.

Interrupt Priority

On supported 8051 hardware configurations, interrupt priority determines which interrupt can preempt another interrupt. HRTOS accounts for interrupt nesting when managing its execution context.

Interrupt Context Management

Nested interrupt execution requires careful management of register state, stack usage and interrupt context.

HRTOS uses its interrupt management model to track interrupt nesting and maintain the required execution state.

Kernel API Restrictions

Not every kernel operation is suitable for execution inside an interrupt service routine.

In particular, nested interrupt service routines must not invoke scheduling or task wake-up APIs. Supported priority-related operations are subject to the system's interrupt nesting rules.

PERFORMANCE

Measured Interrupt Performance

Interrupt response and execution overhead are important considerations in real-time embedded systems.

HRTOS has been tested on 8051-based microcontrollers to evaluate interrupt response and nested interrupt execution.

On an STC12C5A60S2 running at 11.0592 MHz in 1T mode, the measured interrupt execution time was approximately 12.167 microseconds, while the measured nested interrupt execution time was approximately 11.917 microseconds under the documented test conditions.

These measurements provide a practical reference for evaluating interrupt handling overhead on the tested platform.
