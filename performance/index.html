OVERVIEW

Performance Based on Hardware Measurements

HRTOS performance is evaluated through practical measurements on physical 8051 microcontrollers. The evaluation covers execution overhead, real-time response, timing behavior, and operational stability.

On resource-constrained 8-bit microcontrollers, operating system performance is closely related to processor architecture, memory organization, interrupt handling, and scheduling mechanisms. These factors directly influence the execution cost of operating system services.

HRTOS performance testing focuses on measurable execution behavior under defined hardware configurations. Rather than relying only on theoretical specifications, the results provide practical reference data for evaluating the operating system on its target platform.

The following sections present individual measurements and testing procedures, including context switching, interrupt latency, timing accuracy, and stress testing.

TASK EXECUTION

Task Context Switching Performance

Context switching is one of the fundamental operations of a multitasking operating system. Its execution cost directly affects scheduling overhead and task response behavior.

Normal Task Switching

Normal task context switching manages task execution states and restores the required processor context during scheduling operations.

Fast Task Switching

Fast tasks use dedicated register-bank resources to reduce context management overhead under supported execution conditions.

Scheduling Overhead

Different scheduling trigger conditions can produce different execution costs. Measurements distinguish these paths.

Execution Consistency

Repeated measurements help evaluate switching behavior under a fixed hardware and compiler configuration.

Explore Context Switching
INTERRUPT RESPONSE

Interrupt Latency and Response

Interrupt response is an important consideration in embedded real-time systems, particularly when external events require prompt processing.

HRTOS interrupt performance testing examines interrupt execution overhead and nested interrupt behavior on the target 8051 platform.

The measurements provide practical reference values for understanding the time required for interrupt-related execution under specific hardware conditions.

Explore Interrupt Latency
TIME MANAGEMENT

Timing Accuracy and System Time

Accurate timekeeping is essential for periodic task execution, delay operations, and time-dependent application logic.

System Tick

Timer-based system time provides the timing reference for operating system scheduling and time management.

Millisecond Delays

Delay functions can be evaluated against actual elapsed time to examine timing accuracy.

Periodic Execution

Time-based task execution is evaluated in relation to the configured system timing mechanism.

Measurement Deviation

Measured elapsed time can be compared with configured timing intervals to identify timing deviation.

SYSTEM STABILITY

Long-Duration Stress Testing

Performance evaluation also considers sustained system operation and repeated multitasking execution.

HRTOS has undergone extended stress testing on the STC8H8U64K microcontroller. The test involved repeated execution and a large number of test iterations over an extended period.

The test record includes more than 72 hours of continuous operation, 8,842 test rounds, and over 35 million tested variants without reported errors.
