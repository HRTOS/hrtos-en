OVERVIEW

Measuring Operating System Performance

Performance benchmarks provide quantitative information about the execution cost of operating system operations.

For an 8051-based real-time operating system, execution efficiency is influenced by processor architecture, register management, memory access, interrupt handling, and scheduling mechanisms.

HRTOS benchmarks focus on actual execution measurements on physical microcontrollers. The purpose is to provide practical reference data for understanding kernel behavior and evaluating system performance.

The measurements presented on this page are associated with specific hardware configurations and test conditions. They should be interpreted as measured results rather than universal performance specifications.

SCHEDULING PERFORMANCE

Normal and Fast Task Switching

HRTOS provides different task execution context mechanisms for normal and fast tasks. Their measured switching times are shown below.

Task Type Scheduling Trigger Measured Time
Fast Task Scheduling Bit 143.5 us
Fast Task Time Slice 229.5 us
Normal Task Scheduling Bit 394.33 us
Normal Task Time Slice 550.33 us

Fast task switching uses dedicated register-bank resources, while normal task switching manages a more extensive processor context.

The measured difference reflects the different context management mechanisms and execution paths used by the two task categories.

LONG-DURATION TESTING

Beyond Execution Speed

Performance evaluation also includes long-duration operation and repeated system execution.

In addition to short-duration execution measurements, HRTOS has undergone extended stress testing on the STC8H8U64K microcontroller.

The recorded test results include more than 72 hours of continuous operation, 8,842 test rounds, and over 35 million tested variants without reported errors.

These results belong to a separate hardware test platform and should not be directly combined with the STC12C5A60S2 timing measurements.

METHODOLOGY

Benchmark Measurement Principles

Performance values must be interpreted within the context of their measurement methods and execution conditions.

Hardware Execution

Measurements are performed on physical microcontrollers to evaluate actual target execution.

Defined Test Conditions

Processor model, clock frequency, operating mode, and software configuration are identified as part of the test environment.

Operation-Specific Results

Different kernel operations are measured separately to distinguish their execution costs.

Practical Reference Data

Results provide technical reference information rather than guaranteed performance for every supported device.
