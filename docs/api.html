API OVERVIEW

HRTOS Kernel Interfaces

HRTOS provides a collection of kernel interfaces for organizing application execution, managing system resources and coordinating multiple tasks. These interfaces form the foundation of structured embedded application development.

01

Task Management

Create and organize application tasks, manage execution and coordinate task lifecycles.

  • Task registration
  • Task organization
  • Task execution control
  • Task priorities
02

Time Management

Provide timing-related services for periodic execution, delay operations and time-dependent application logic.

  • System time management
  • Delay services
  • Timed waiting
  • Periodic execution
03

Synchronization

Coordinate task execution and shared resource access through kernel synchronization services.

  • Semaphores
  • Mutexes

  • Unified wait mechanisms
TASK MANAGEMENT APIS

Task Registration and Execution

Task management interfaces allow application functions to be organized into independent execution units. HRTOS coordinates these tasks through its scheduling mechanisms.

Task Registration

Register application task functions with the operating system and configure the corresponding task execution parameters.

Task Identification

Organize registered tasks using task identifiers for system management and application coordination.

Task Priority

Configure task execution priorities according to application scheduling requirements.

Fast Task Management

Support dedicated fast task execution mechanisms for applications with demanding response-time requirements.

SCHEDULING SERVICES

Task Scheduling and Execution Control

HRTOS scheduling interfaces coordinate task execution according to system scheduling policies and application execution requirements.

01

Priority-Based Scheduling

Organize task execution according to configured scheduling priorities.

02

Task Switching

Coordinate execution context transitions when scheduling conditions require a task switch.

03

Execution Coordination

Manage task execution and coordinate application activities through kernel services.

TIME MANAGEMENT APIS

Timing and Delay Services

Time-related interfaces provide application tasks with mechanisms for waiting, periodic execution and time-dependent operations.

Delay Operations

Allow application tasks to suspend execution for configured time intervals.

Millisecond Timing

Provide millisecond-oriented timing services for applications that require time-based execution.

Periodic Task Execution

Organize recurring application operations using timing and scheduling services.

Timed Waiting

Coordinate task waiting operations with time limits and other kernel synchronization mechanisms.

SYNCHRONIZATION APIS

Task Synchronization Mechanisms

HRTOS provides synchronization services for coordinating task execution, controlling shared resource access and managing application events.

01

Semaphores

Coordinate task execution and manage synchronization conditions between independent application tasks.

02

Mutexes

Protect shared resources and coordinate exclusive access between tasks, including priority inheritance support.

03

Events

Provide event-based synchronization for coordinating application activities and task execution.

INTER-TASK COMMUNICATION APIS

Inter-Task Communication

Communication interfaces allow application tasks to exchange information and coordinate data processing operations.

Message Queues

Exchange messages between application tasks through queue-based communication mechanisms.

Mailboxes

Provide mailbox-based communication for transferring information between independent tasks.

Message Management

Organize application messages and coordinate message-related task operations.

Unified Wait Mechanism

Coordinate task waiting with supported synchronization and communication objects through unified waiting services.

INTERRUPT MANAGEMENT APIS

Interrupt-Related Services

Interrupt-related interfaces support application integration with hardware interrupt processing and the HRTOS execution model.

01

Interrupt Integration

Coordinate interrupt handling with application tasks and system execution.

02

Interrupt Priorities

Organize interrupt execution according to the hardware interrupt priority configuration and system requirements.

03

Interrupt and Task Coordination

Coordinate hardware event processing with task-level application operations.

Interrupt context restrictions must be observed when using kernel services. Scheduling-related and task-wakeup operations should not be called from nested interrupt contexts where they are not permitted.

Task Configuration

Configure the available task resources and application task limits.

Scheduling Configuration

Configure scheduling-related parameters and task priority arrangements.

Timing Configuration

Resource Configuration

DEVELOPMENT GUIDELINES

Working with HRTOS APIs

Follow appropriate development practices when integrating kernel interfaces into embedded applications.

Understand Execution Context

Identify whether an interface is intended for task context or interrupt context before using it in application code.

Manage Shared Resources

Use appropriate synchronization mechanisms when multiple tasks access shared application data or hardware resources.

Configure Resources Carefully

Ensure that task limits, communication objects and other kernel resources are configured according to actual application needs.

Consider Timing Requirements

Design task execution, waiting operations and interrupt processing according to the timing requirements of the application.
