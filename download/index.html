DEVELOPMENT ENVIRONMENT

System Requirements

Review the recommended software environment and hardware resources before starting an HRTOS project.

Compiler and Toolchain

HRTOS is designed for the Keil C51 development environment and 8051-compatible toolchains.

Microcontroller Platform

An 8051 or MCS-51 compatible microcontroller is required. STC microcontrollers are among the supported development targets.

CODE Memory

The full HRTOS configuration requires at least 8 KB of CODE memory.

XDATA Memory

The full HRTOS configuration requires at least 1 KB of external data memory.

Development Board

An 8051-compatible development board is recommended for hardware testing and application development.

Programming and Debugging

A compatible programmer, debugging tools and serial communication interface are recommended.
